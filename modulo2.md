1-Seção: Diferença entre Git & GitHub. Git é um sistema de controle de versões distribído, que registra o histórico de alterção de um projeto; GitHub é uma plataforma remota, que guarda e gerencia os projetos criados publicados, compartilhados por uma equipe contribuíndo para a colaboração. 2-Seção: Explicando o comando Fetch, Pull e Push. O comando fetch baixa todas as informações do repositório remoto para o computador local; O comando Pull serve para baixar as atualizações de um repositório remoto (GitHub) e juntar elas no computador local; O comando Push serve para enviar um projeto COMMITED para o repositório remoto. 3-Seção: Relato de recuperação de erro. Existem distintos jeitos de recuperar um erro, cada um servindo para um status do erro. Por exemplo, Caso o erro tenha sido antes do commit, usar um restore <arquivo> serve. Se o arquivo esta com status staged, ou seja, preparado, usa-se outro método: git restore --staged <arquivo> e assim existem outros métodos.
