1-Qual o tema do Guia? Fundamentos da Linguagem C; 2-Quem é o público-alvo? Estudantes sem experiência em Programação; 3-Qual o resultado esperado? Ao finalizar o guia, espera-se que o leitor seja capaz de programar o básico da Linguagem C, criar exercícios de prática, e melhorar a lógica de programação. Quais são os pré-requisitos? Para iniciar seu aprendizado é necessário que o aprendiz tenha uma máquina para programa, ou seja, um computador desktop ou um notebook/laptop; Também é necessario uma IDE, uma ambientação, resumindo, é onde se faz o código. Para C, considere usar o VS CODE: https://code.visualstudio.com/download?_exp_download=fb315fc982 ou o Dev C++: https://www.dev-cpp.com/. Entre essas IDEs sugiro que usem o DEV C++, pois não é necessário configurar extensões nem caminhos, diferente do VS CODE. 4- Estrutura do guia. - docs/01-introdução.md; -docs02/conceitos.md; docs03/exercicios.md; -docs04/referências.md. 5-Como navegar: Recomenda-se o uso do DEV C++ por ser mais fácil e intuitivo o uso, portanto, instale e abra o DEV C++; Ao abrir, clique na folha em branco logo abaixo da guia Arquivo ou pressione Ctrl + N. Assim, ja abriu sua IDE e já está preparado para codar. Autoria: Guilherme Comaccio, 15/08/2026
